# Flip.ro Test Suite

Complete test automation for Flip.ro Romanian e-commerce.

## Structure
- `packages/playwright-tests/` - Playwright TypeScript tests
- `packages/cypress-tests/` - Cypress JavaScript tests
- `packages/api-tests/` - Python API tests
- `packages/performance-tests/` - k6 load tests
- `packages/ai-tools/` - AI-powered QA tools

## Quick Start
```bash
make setup
make test-all
